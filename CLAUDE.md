# AudioBridge — instruções para o Claude Code

- Responda em português (pt-BR).
- Antes de qualquer trabalho, siga a seção **"Como colaborar"** do `README.md`. Pontos principais:
  - nunca commitar no `main`;
  - uma tarefa por PR;
  - evidência de teste no PR;
  - nada de nomes de pessoas ou mídia no repo, que é público.
- A fonte da verdade é a spec `docs/superpowers/specs/` e o plano da fase atual `docs/superpowers/plans/`.
- Máquina nova no Mac sem setup feito: execute "Setup no Mac → Parte 2" do `README.md`.
- Callback de áudio: sem alocação, lock, log ou chamada bloqueante.
